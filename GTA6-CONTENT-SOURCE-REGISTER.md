## 0. Honest statement of evidence limits (read first)

| Capability | Status for this project |
|---|---|
| Actual in-game testing / screenshots / control-scheme screens | **NOT performed.** No console or game build was available to the author of this register. No page may claim personal gameplay testing. |
| Google Search Console data | **Not accessed.** No authorized browser session was exposed to the agent. No impressions/clicks/queries are cited anywhere. |
| Source retrieval method | A web-search tool returning **summaries with redirect (grounding) URLs**. Direct article URLs, publication dates and full text were **not captured**. Publication names below are those named in the search summaries and are therefore recorded as *attributed, not independently re-fetched*. |
| Rockstar official material | `https://www.rockstargames.com/VI` returned HTTP 200 from the build machine. `https://support.rockstargames.com/` **timed out** from the build machine (15 s) — the link is used as the primary authority but was not re-validated from here. |

Consequence: every gameplay fact added by this project is labelled **COMMUNITY REPORTED** or **INDEPENDENTLY REPORTED (attributed)** unless it was already part of previously accepted site content. Nothing is labelled **IN-GAME VERIFIED** by this project.
Where the evidence is insufficient, content is **not published** (see "Intentionally unpublished" in the final report).
