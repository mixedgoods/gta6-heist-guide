Section 4 · NVMe M.2 Storage

Storage Upgrades (PS5 Heatsink & PC NVMe)

Optional Upgrade

An internal SSD upgrade is completely optional if you only keep a few games installed at a time. For PS5 internal expansion, Sony requires an M.2 2280 PCIe Gen4 x4 NVMe SSD rated at 5,500 MB/s+ with a cooling heatsink. If you buy a bare drive like the Samsung 990 PRO 4TB below for PS5, you must install a compatible third-party M.2 heatsink; for PC/laptop builds it installs directly.
