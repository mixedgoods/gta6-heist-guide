Save and progress

Save game not working COMMUNITY-REPORTED

Possible documented causes

  • A save may fail or appear to not complete if the game, console software or storage is in a bad state (reported by players; not a documented Rockstar cause).

Safe first checks

  • Stop and look: open the load menu and check every listed slot (autosave and manual slots are shown separately) before saving over anything.
  • Close the game fully from the console home screen (not Rest Mode), then relaunch and check again.
  • Confirm you are signed in to the same PlayStation Network / Xbox profile and Rockstar account as before.
  • Check free storage on the console drive. Do not delete saved data to "fix" a save problem.
  • Make a save to a different manual slot and load it to confirm it worked.

Relevant storage locations

  • Saved data location: your console's saved-data settings (menu names vary with system software version) and, where enabled, the platform cloud. Check both before concluding that a save is gone.

Community-reported workarounds (not confirmed fixes)

  • Players recommend rotating between several manual slots instead of relying on autosave alone.

Official support

  • Rockstar Games Support (primary authority for GTA VI troubleshooting)
  • PlayStation Support for console steps
  • Xbox Support for console steps

Weapons disappeared COMMUNITY-REPORTED

Possible documented causes

  • Some missions may issue a temporary loadout and remove your own weapons for story reasons (community-reported explanation, not confirmed).

Performance and technical

GTA 6 crashing on PS5 COMMUNITY-REPORTED

Possible documented causes

  • Reported crashes have no documented single cause.

Safe first checks

  • Confirm the console system software and the game are fully updated.
  • Fully close and relaunch the game; avoid resuming from Rest Mode.
  • Keep some free space on the console drive.
  • Note the error code if one appears and report it to Rockstar Support.
  • Sony documents Safe Mode and cache options for the PS5; use only the cache option and avoid any option that resets or initializes the console.

Community-reported workarounds (not confirmed fixes)

  • Some players report that clearing the PS5 system cache from Safe Mode helped. This is community-reported and does not delete saves; check Sony's instructions for your system software.

Official support

  • Rockstar Games Support (primary authority for GTA VI troubleshooting)
  • PlayStation Support for console steps

Note

Rockstar Support is the primary authority; use it for error codes and ticket submission.

Frequently asked questions

Should I delete my save data to fix GTA 6 problems?

No. Deleting saved data, resetting a console or reinstalling the game can permanently remove saves that are not backed up to the cloud. Use the safe checks first and follow official PlayStation, Xbox or Rockstar instructions.

Where do I get official help for GTA 6?

Rockstar Games Support is the primary authority for GTA VI technical help. Use PlayStation Support or Xbox Support for console-level steps.

Why did my weapons disappear in GTA 6?

Some players report that certain missions issue temporary loadouts. This is community-reported, not confirmed. Check the active character, the safehouse locker and the vehicle trunk before assuming loss.

Is there an official GTA 6 patch note for the latest build?

A newer build (PS5 01.002.002, Xbox 1.0.2.2) was independently reported on November 23, 2026, but no official Rockstar notes had been published at that time.
